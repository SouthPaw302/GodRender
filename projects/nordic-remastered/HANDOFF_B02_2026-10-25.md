## How to run GodRender

### Local / sandbox workstation

From a checkout of GodRender:

```bash
git checkout song/nordic-remastered
git pull
python tools/verify_consolidation.py
python godrender_boot.py
python studio/stack.py
```

Then open:

`http://127.0.0.1:8080`

The required production gate is a real:

`GODRENDER BOOT PASS`

Do not process guarded production media if boot does not pass.

Windows:
```bat
studio\start_windows.bat
```

Termux:
```bash
bash studio/start_termux.sh
```

### Verification

```bash
python tools/verify_consolidation.py
PYTHONPATH=studio python -m unittest discover -s tests -p 'test_*.py' -v
PYTHONPATH=studio python studio/selftest.py
```

For the B02-specific workflow, after source acquisition is corrected:

```bash
gh workflow run nordic-b02-director-fx.yml \
  --repo SouthPaw302/GodRender \
  --ref song/nordic-remastered
```

Watch it with:

```bash
gh run list --repo SouthPaw302/GodRender --branch song/nordic-remastered
gh run watch <RUN_ID> --repo SouthPaw302/GodRender
```
