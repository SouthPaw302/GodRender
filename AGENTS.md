# GodRender — Agent Operating Contract

GodRender is the only **active video repository**. Work on its exact checked-out branch and identify the GitHub commit in every handoff. Other repository names in import metadata are historical lineage and are **not instructions to switch repositories or resume a second video stack**.

See [native GodRender guardrails](docs/NATIVE_GUARDRAILS.md) for binding processing, provenance, acceptance and independent-operation rules.

## Mandatory startup
1. Check the actual `SouthPaw302/GodRender` ref and `HEAD`. Read this file and `README.md`.
2. Run `python tools/verify_consolidation.py` to verify pinned source integrity. Run `python godrender_boot.py` before guarded production work. **Only** a genuine `GODRENDER BOOT PASS` with the native runtime's exact PASS string, main SHA and session attestation permits production operations.
3. Read the verified runtime's `PRIME_DIRECTIVE.md`, generated `SECOND_BRAIN.md`, `SOUL.md`, the active production's Operating Order and protected-source rules. Native GodRender schema/attestation strings are machine interfaces; never bypass validation or substitute an old engine.
4. Consult the [External Brain](https://docs.google.com/spreadsheets/d/1Xi2wSER-vEIjy52FTKA5RvMXNnGrTxoYiEoPhyXw77c/edit): FX Pixel Application Atlas, composition recipes, recoverable render lineage, per-branch source review. Treat old branch names only as provenance.
5. Resolve every FX to exact code, SHA, ROI/masks, parameters, approved gate and real execution route. Report missing support instead of inventing an adapter.
6. Preserve previously approved original media and image identity; do not import rejected shots or repurpose song-specific masks/camera settings without a new proof.
7. Test a short moving scene first, then transitions and sections, then complete music-synced movie. Log Git SHA, actual proof/CI URL, decoded media hash, guard results and creative review.
8. Do not merge unverified changes, publish a master without authorization, overwrite archival sources, or mutate any old video repo. Commit to **GodRender only**.
