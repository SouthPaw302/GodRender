# GodRender External Production Brain

**GodRender is the sole active GitHub video project.**

[Open the Drive production brain](https://docs.google.com/spreadsheets/d/1Xi2wSER-vEIjy52FTKA5RvMXNnGrTxoYiEoPhyXw77c/edit)

Authority: explicit user instruction → actual GodRender project/Operating Order → validated runtime guard/FX contract → human approval. Drive indexes technical history and findings; it cannot approve or execute an FX.

Before a new shot:
1. Verify the current GodRender Git SHA and bootstrap status.
2. Search **FX PIXEL APPLICATION ATLAS** for what actually changes: per-pixel operation, image-region masks, parameter signature, inputs and output.
3. Search **FX COMPOSITION RECIPES** for effect ordering and protected-area boundaries.
4. Use **RECOVERABLE RENDER LINEAGE** and **PER-BRANCH PACKAGE REVIEW** to find working techniques from earlier productions—including films rejected for unrelated reasons.
5. Resolve copied code by Git blob SHA and active gate. Historical branch/repository fields are **provenance**, not alternate operational projects.
6. Produce an A/B moving proof, record actual technical QC, and request Director artistic acceptance before film assembly.
7. Update the brain with evidence only after a run; do not claim a merge, approved FX or finished film from a registry name.

`config/brain_source_index.json` is a dated collection of legacy branch heads, not an active repository router. New changes land exclusively in GodRender.

Legacy machine-compatibility details are documented in [`COMPATIBILITY_DEBT.md`](COMPATIBILITY_DEBT.md).
