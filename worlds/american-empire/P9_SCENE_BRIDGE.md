# P9 — Source-bound Browser → GodRender → Godot 3D Bridge

This production proof preserves `world/american-empire` and protected `main`. In a disposable CI checkout, native production boot runs using a **local-only** `song/american-empire` alias with the verified GodRender OS and its production/workflow guards. No new remote branch exists.

## Actual execution chain
1. Canon integrity + P1–P7 Python regression checks.
2. Build the existing Vercel/browser simulation from actual source (not an invented or hard-coded state).
3. Chromium initializes P5, P6, P7, exports the **real source-hashed 12-year P7 receipt**. No original film assets enter the client.
4. Python `tools/export_godot_scene.py` fully validates the P7 run hash, 12 annual snapshot SHA chains, and selected actor/year. It reads approved P6 place references and the P8 same-world film location, then writes a minimal source-bound `scene_contract.json`.
5. Godot 4 launches an independent **3D Node3D scene**, not the old 2D P4 graph. The 3D proof procedurally instantiates simple buildings and streets, a **non-identifying character marker**, camera/light, and service/independence indices from the actual world state. Camera orbits, and Movie Maker records actual frames.
6. FFmpeg encodes a derived, technical proof. An independent verification checks chain, source equality, three changed images, actual movie frame count, and zero imported private film assets. GitHub attaches receipts/preview.
7. Altering one numeric value in the P7 receipt without recalculating source hashes must be rejected.

## Authority and limits
- Every numeric service or autonomy value is **scenario_only** and **not** a factual claim about Paris, accessions or canon.
- The film's calendar year was not verified: 2027 is a **provisional simulation placement**.
- **No Claire face/costume, no apartment geometry, no media, no film scene** is reconstructed or claimed. All Godot geometry is abstract schematic proof.
- The existing Godot P4 project, all old AE source material, Drive originals, Vercel interface, FX pipelines and `main` remain intact.
- This is a **batch handoff** from the working browser simulation to native Godot in a guarded production checkout. Not a persistent Godot server, automatic 3D worldwide generator, synced Drive render store, or live two-way UI.
- A PASS requires an actual new GitHub Actions workflow execution and actual derived images. Code alone is not proof.
