# Derived viewer data (never canon)

The Godot project requires `world_bundle.json`, generated by:

```bash
python3 worlds/american-empire/tools/build_explorer_bundle.py
```

The output is ignored by Git because it is regenerated byte-for-byte from verified P1/P2/P3 sources. No source canon or media are copied here. The model scenario snapshots are hypothetical. P4 Godot graphics are a faction/system schematic, not a geographic map.
